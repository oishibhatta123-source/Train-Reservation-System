
# Train Reservation System

A simple Train Reservation System developed using C programming for a Data Structures and Algorithms academic project.

## Features

- Book train tickets
- Cancel tickets
- Automatic seat assignment
- FIFO waiting list
- Display passenger details
- Check seat availability

## Technologies Used

- C Programming
- Visual Studio Code
- GCC Compiler

## Data Structures

- Arrays
- Singly Linked Lists
- Queues
- Structures

## Project Capacity

- Confirmed Seats: 5
- Maximum Waiting List: 100

## How to Run

Compile the project:

```bash
gcc -Iinclude src/main.c src/booking.c src/passenger.c src/queue.c -o train.exe
```

Run the project on Windows:

```bash
.\train.exe
```
